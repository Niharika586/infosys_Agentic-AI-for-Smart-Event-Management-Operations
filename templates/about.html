Understanding RegisterAI

A deep dive into the objectives, benefits, technology and AI workflow behind this system.

Project Description

RegisterAI is a full-stack, AI-augmented registration and attendee management platform developed as part of the Infosys Springboard Virtual Internship — Milestone 1. It streamlines the entire event lifecycle: attendees register through a validated form, data is persisted in SQLite via a Flask backend, and a rule-based AI module continuously mines that data to surface predictions and recommendations for organizers through an interactive dashboard.

Objectives

  • Build a responsive, production-style multi-page web app
  • Implement secure CRUD operations on a relational database
  • Apply rule-based AI for predictive event analytics
  • Deliver real-time dashboards with dynamic charts
  • Enable QR-based digital check-in for events
