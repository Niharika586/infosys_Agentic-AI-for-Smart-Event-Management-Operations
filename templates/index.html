Project Overview

RegisterAI unifies event registration, attendee management and AI-driven decision-making into a single, elegant dashboard. Built for Infosys Springboard's Virtual Internship Milestone 1, it demonstrates a complete full-stack workflow — from data capture to predictive analytics.

  • Smart registration form with real-time validation
  • Rule-based AI engine for attendance & no-show prediction
  • Live analytics dashboard with animated charts
  • QR-based check-in with live attendance counter

End-to-End Workflow

Register → Validate → Store → Predict → Visualize → Check-in → Report. Every stage is connected through a live Flask + SQLite backend.
